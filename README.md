# FARO CFDI

Canal oficial de distribución y actualizaciones de FARO CFDI.

FARO CFDI es una aplicación de escritorio para la administración, consulta y generación de reportes de comprobantes fiscales digitales.

## Descargas

Las versiones disponibles se publican en la sección Releases.

## Seguridad

Cada instalador se publica acompañado de su suma de comprobación SHA-256.

## Aviso

Este repositorio contiene únicamente archivos de distribución. El código fuente de FARO CFDI no se publica en este repositorio.
